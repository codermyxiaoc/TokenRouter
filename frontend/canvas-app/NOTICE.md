# Infinite Canvas

本子应用的画布交互、连线、小地图、缩放、图片裁剪、蒙版绘制、主题、选择组件、配置节点与提示词组装交互源于 [basketikun/infinite-canvas](https://github.com/basketikun/infinite-canvas)，参考提交 `3a6b64b602ad062b29fac66902ed18a7ef5fd9dc`（v0.20.0）。原作者 Copyright (c) 2026 basketikun，MIT 许可完整保留于 `LICENSE.infinite-canvas`。

TokenRouter 对用户隔离、云端保存、素材留存、模型目录与生成执行进行独立集成，不包含原项目的个人渠道、自定义脚本、远程插件或本地 Agent 执行功能。
