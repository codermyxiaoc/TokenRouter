# 云端无限画布

云端画布替换 `/creative` 的旧图片创作台界面。编辑器复用 Infinite Canvas v0.20.0 的结构和画布交互，主题配色与 Sub2API 保持一致，来源提交为 `3a6b64b602ad062b29fac66902ed18a7ef5fd9dc`，按原 MIT 许可保留署名。普通用户只能使用管理员配置的图片、文本、独立 Video 平台视频、Grok 视频和 Grok TTS 模型。

本文拥有画布文档、素材留存、任务关联和前端会话边界。图片资金生命周期仍由[创作台任务](creative_studio.md)拥有，独立 Video 平台的资金生命周期由[独立视频任务](video_tasks.md)拥有，Grok 视频沿用[原任务归属与结算](../interfaces/grok_upstream.md#grok_video_ownership)。旧浏览器画布不迁移，也不读取固定 IndexedDB 中的旧提示词或素材；旧任务和账务记录不删除。

<a id="session_boundary"></a>
## 登录与隔离

Vue 宿主通过同源 `/canvas-app/index.html` 加载 React 画布。消息命名空间为 `tokenrouter-canvas`，双方同时检查精确 `origin` 和 `source`，子应用从父窗口获取当前用户编号和 JWT，令牌仅留在运行时内存。JWT 刷新不会重建任务；切换用户销毁 iframe。宿主在 iframe 更新完成后同步会话，并校验当前 iframe 的用户归属，防止旧窗口的迟到消息获得新用户令牌。登出或关闭子应用会中止请求、撤销对象 URL 并清除内存素材。

服务端从 JWT 推导用户，不相信画布正文中的用户编号。每次画布、素材、执行任务读取和变更都验证所有者；随机 UUID 仅是标识，不构成授权。图片旧工作区标识在桥接层由画布 ID 固定生成，不能由浏览器切换到他人任务。

只有内置画布 HTML 允许 `SAMEORIGIN` 嵌入；其它主站页面继续 `DENY`。画布 CSP 只允许本站脚本和 API，不允许远程插件、任意脚本、自定义上游密钥、外部 WebDAV 或本机 Agent 执行桥。画布导入不能携带自动执行逻辑，也不会触发生成。

<a id="persistence"></a>
## 画布持久化

PostgreSQL 保存私人画布标题、节点、连线、视口、提示词与 revision。读取成功不代表写入成功；保存必须得到数据库确认。更新携带读取时的 revision，其他窗口已经修改时返回 `409 CANVAS_REVISION_CONFLICT`，不能用后到写入静默覆盖。

画布正文不保存 base64 文件、临时 `blob:` 地址、供应商凭据或可执行代码。媒体通过私有 asset ID 关联。文档单份上限 4 MiB；资产上传、读取、任务引用分别校验类型、大小和用户归属。删除画布只改变用户展示数据，不取消上游任务，也不删除资金账本。

<a id="asset_retention"></a>
## 素材保留和清理

上传素材与生成结果从创建时刻起按 `creative_canvas_asset_retention_hours` 保留，默认 **168 小时（7 天）**，管理员可在“系统设置 → 创作台”配置 **1–8760 的整数小时**。修改只影响之后的新上传和新归档素材；每张素材首次登记的到期时间固定，已存在素材及同一产物归档重试不会因配置变化延长或缩短。到期后服务端立即拒绝内容读取并返回 `410 CANVAS_ASSET_EXPIRED`。画布和节点位置继续保存，界面显示素材已过期；打开旧画布不会自动补生成。此配置与异步 Images 的默认 24 小时保存期独立。

私有文件存入持久数据目录，数据库只记录文件索引、长度、摘要、归属与到期时间。图片在标记 `ready` 前须能完整解码；伪装或截断文件不会成为可引用素材。视频使用流式读写，不把完整视频长期放入内存或 Redis。单次上传最多 64 MiB，其中图片最多 32 MiB；生成视频最多 512 MiB；每用户素材配额 2 GiB。存储配额校验必须包含并发上传预留，不能仅在上传前读一次已用量。

后台启动时补偿清理，此后每周清理到期物理文件；公开设置 `creative_canvas_asset_retention_hours` 下发当前生效的保存期（小时），创作台页面描述按它换算天数，旧后端缺失时回落 7 天；因此文件实际占用磁盘的时间可能长于其保存期，访问权限始终以每张素材登记的 `expires_at` 为准。清理只操作服务管理的素材路径，保留元数据到期状态以支持画布占位；不会改写预扣、扣费、退款或平台用量。部署时须持久挂载素材目录，多实例使用同一持久目录，避免不同实例读取不到素材。

<a id="execution"></a>
## 生成与计费

管理员继续配置 `creative_model_settings`，旧项省略 `media_type` 时按图片处理。视频项明确设置 `media_type=video`、允许的 `video_endpoint`、默认时长/分辨率/比例以及参考图、参考视频数量；数量是管理员在协议上限内的额外收紧，协议上限来自模板能力或内置协议声明，见[参考素材上限](../interfaces/cloud_canvas.md#video_reference_limits)。Grok 分组的视频使用创作台专用端点 `grok`；独立 Video 分组的 `video_endpoint` 只用于目录归类，取模型在账号上绑定的内置协议端点，绑定模板协议的模型归入 `unified`，两类不能互换。目录按用户实际分组权限和可调度能力过滤；提交时再次校验，不能只靠页面隐藏。

音频项使用 `media_type=audio`、固定站内模型 `grok-voice-tts` 和 `operations=[generate]`。仅在 Grok 分组存在可调用 Voice 的真实账号时提供候选；语音沿用正式 `/tts` 的文本账号能力与 `grok-4.5` 调度准入，不受图片生成开关或图片付费资格限制。声音、格式和语速能力由服务端派生，管理员只配置分组与模型白名单，用户无需填写上游地址或密钥。

文本项使用 `media_type=text`、`operations=[generate]`，仅开放已有正式 Chat Completions 路由、当前账号可调用并有明确 Token 价格的文本模型。图片开关不授予或阻止文本能力；组协议、用户组权限、模型映射和实际账号准入继续生效。首期只接受纯文本与连接文本引用，不接受图片、视频或音频参考；输入最多 8000 个 Unicode 字符，输出上限可选 1–4096 Token，默认 1024。

独立 Video 平台的画布模型开放 1–60 整数秒、480p/720p/1080p、自定义数字 p 分辨率、常见比例与自动比例；这是画布可编辑范围，不保证每个上游都支持。自定义分辨率为 1–65536p，比例只从运行时目录选择，不提供自由输入。原配置分辨率/比例首项、时长最小值继续作为默认值，原生 2k/4k 与精确尺寸档位保留。运行时扩展目录，不迁移管理员配置、已提交参数或任务价卡；分组权限、端点准入、参考图上限继续生效。正式协议限制与价格匹配仍在原视频任务链路检查，不能把不支持或缺价的 768p 自动降成 720p。

管理员可为每个“分组 + 视频模型”配置可选的 `usage_notes` 使用说明，独立 Video 与 Grok 视频共用此展示合同。说明最多 2000 个 Unicode 码点，按纯文本保存与显示，保留换行；未填写或清空时隐藏。普通视频节点在生成操作栏下方展示两行摘要，较矮窗口收为单行，完整正文通过独立可滚动详情弹窗阅读；配置节点在生成按钮旁提供同一详情入口。切换模型或分组时切换对应说明，不解析 HTML，不向外部站点取文案，也不把说明附加到提示词、生成参数、任务指纹或账务。后台更新后，用户下次加载模型目录即可获取新说明；现有任务参数不随文案变更。

Grok 视频沿用原计费能精确表达的 **1–15 整数秒**和 **480p/720p/1080p**，关闭自定义分辨率；常见比例与自动比例仍从目录选择。保存配置、运行目录和执行提交共用这一边界，避免超出原合同的时长或分辨率被静默按 15 秒或 480p 计费。表单默认仍为 5 秒、720p、16:9；前端按服务端能力设置时长上限并禁用自定义分辨率，不影响独立 Video 的范围。

画布的自动比例在账号确定后按实际适配处理。秘塔 H3 只支持横屏或竖屏，服务端根据已校验参考图的方向选择 16:9 或 9:16；无参考图时优先使用合法的模型默认比例，否则使用 16:9。该内部提示不能由 API 请求注入，不改变普通 API 或其他适配的自动比例语义。实际转换后的尺寸继续进入原报价、任务快照和预扣流程；已受理任务按原参数恢复，不因新比例规则重新提交。

云端画布对实际使用秘塔 H3 适配的新请求施加本站单张参考图 **2 MiB** 原始文件上限，以避免大体积 Base64 JSON 在上传阶段长时间等待；这不是供应商官方大小声明。原素材保持完整，不自动压缩或缩放，由用户换用较小图片。目录确认该模型和端点的可用候选全部使用 H3 时向前端暴露大小限制，界面按实际发送的参考图提前提示；后端根据所选账号方案和已校验素材的真实字节数，在创建视频任务、报价与预扣前再次检查。普通 API 和其他适配不继承此画布限制；混合候选仍可按原资格流程检查其他支持的账号。已有任务优先恢复，不因新限制被重新提交、失败或退款。

一次用户主动生成对应一个持久执行或图片批次，固定绑定用户、画布、节点、参数指纹和后端任务 ID。图片批次按模型单次输出合同拆为独立 execution，在同一数据库事务内全部登记；普通模型可选 1–8 张，MJ 可选 4 或 8 张。每个子执行沿用原任务幂等和账务，部分失败不影响已经成功的结果。重复点击或网络重放使用同一幂等键；同键不同参数或张数返回冲突。拖动、缩放、保存、复制、删除、导入、刷新、轮询和素材清理均不发起模型请求。

生成准入计入实际素材与在途成品预留，继续遵守每用户 2 GiB 配额；视频每子执行预留 512 MiB，其它类型预留 128 MiB。只因已有任务预留而临时不足时使用 `429 CANVAS_EXECUTION_LIMIT`，实际素材与本次预算已超配额时使用 `413 CANVAS_STORAGE_LIMIT`；两者均在建执行和上游提交前拒绝，使用预扣的媒体也不会先冻结费用。容量按整批及用户事务锁检查，不通过提高限额、部分受理或自动重发来规避。

图片、视频节点直接接收自身生成结果；多张图片以同节点叠卡展示，可展开、切换主图或主动提取成新节点。生成配置节点仍创建一个媒体结果节点。生成前先持久化提交意图，保存失败时不提交；响应丢失时保留原参数与幂等键，图片轮询按批次键恢复，也可点击核对提交重放同一请求。旧批次响应不能覆盖新批次，导入、复制和导出会清除执行意图。余额不足、参考图过期及模型能力不匹配按已知错误码分别显示，不再统一显示为参数校验失败。独立 Video 缺价 `VIDEO_PRICING_UNAVAILABLE` 单独提示管理员配置模型或分辨率价格，历史失败记录读取时也按错误码显示新提示；该拒绝发生在生成提交和预扣前，不通过放行或自动填价绕过原报价链路。

- 图片：复用 `CreativePublicService` 和 `creative_hold/capture/release/settle`。MJ 一次返回四张时仍预留四张、按实际归档成功的张数结算，各输出分别归档展示；归档永久失败的输出不计费，见[只为已交付的成品扣费](creative_studio.md#creative_delivery_billing)。
- 音频：内部使用 `CreativeRun.operation=tts`，输出数固定为一段，复用同一预扣、捕获、释放与幂等账本。按实际朗读文本去首尾空白后的 Unicode 字符数计价；优先使用渠道 `tts` 的连续单位价格，再使用分组 TTS 每百万字符价格，空值沿用正式语音默认价、显式零价保持免费。创建时冻结整段文本基础费用与基础分组/用户/订阅倍率，不套图片独立倍率；正式 `/tts` API 的成功后扣费行为不变。
- 文本：通过进程内私有路由进入原 Chat Completions 鉴权、分组协议、审核、调度与 Token 结算，不对自身 HTTP 端口发回环请求，也不套媒体固定预扣价。收到真实用量后先保存纯文本结果与安全的冻结结算命令，再调用原 `UsageBillingRepository.Apply`；资金回执与原余额、订阅、额度、去重事务一起提交。恢复使用原命令和原分摊回执补写日志，不重新报价、生成或重复扣款；内部 `creative_text:{execution_id}` 身份不能由公网参数伪造。只有确认用量日志与账务后才将文本执行置为成功，结果按纯文本写入目标节点。
- 独立 Video 平台视频：复用内容审核、并发和消费准入，把画布参数构造成与 `/v1/videos` 相同的统一请求后调用 `VideoTaskService`，各账号协议的请求体转换与正式入口共用同一实现，画布不再按端点拼装厂商格式；沿用 `video_hold/capture/release`，不在画布层再次预扣。恢复仅查询冻结的任务和原 Key，不按当前模型目录重新创建任务。
- Grok 视频：通过进程内私有桥复用正式 Grok 网关，任务由 `LegacyVideoRuntime` 查询并按原 Grok 合同在完成后结算，不进入独立 Video 的预扣账本。发送防重、原任务关联和归档边界见[Grok 视频执行与恢复](#grok_video_execution)。
- 结果：执行成功与输出素材关联在原任务完成结算后对外确认；后台可先持久化已确认的媒体字节，避免临时缓存过期丢失成品。图片写入私有存储且资产索引确认后才 ack 临时结果；关闭页面不停止归档。归档失败仅重试存储，不重试模型，也不改变已确认费用。
- 异常：上游受理不明确继续沿用原任务核对逻辑；浏览器等待超时不等于失败、取消或退款。执行仍为 `running` 时，受理待确认、完成待结算和失败预算待处理分别投影安全阶段码与说明，画布中央显示静态“正在核对”提示并继续轮询，保持新生成按钮禁用。任务恢复正常进度后清除核对提示；结算成功后归档，预扣释放后显示失败。复制、导入、导出清理节点的核对展示字段；资金和权限判断不依赖这些展示字段。

图片上游结果未知的判断仅适用于原任务 `running`，不能用遗留的提交栅栏覆盖已完成、待结算或待释放的状态。图片结算、释放分别使用 `CREATIVE_IMAGE_SETTLEMENT_PENDING`、`CREATIVE_IMAGE_RELEASE_PENDING`；同步请求超时或中断且没有可查询的上游 ID 时，提示已停止自动重发并给出已鉴权的原任务编号，说明超过原执行时限仍无结果将自动失败并释放预扣、不会扣费，不暗示后台一定能取得成品；规则见[结果未知即释放](creative_studio.md#creative_unconfirmed_release)。临时查询失败保留已有核对原因，不重新显示成普通生成中。

画布图片复用创作台的两账号安全切换和持久总时限：确定未受理时才换同组备用账号，界面仍跟踪同一原任务，不创建第二个预扣或执行记录。无明确受理结论、已产生用量/任务/输出、归档失败或结算失败均不能重新生成；超时核对提示优先使用原任务保存的绝对截止时间，不因重启或设置变化延长等待。具体边界见[创作台任务](creative_studio.md)。

图片执行错误保留本站定义的安全类别，区分上游审核、账号认证/权限、上游余额/额度、模型、参数、限流、超时和服务异常；历史只有 `UPSTREAM_STATUS_*` 的错误按 HTTP 类别展示。独立 Video 在原账本确认 `released` 后才显示失败原因和“预扣已释放”，从已存原响应的固定错误字段归类，不把提示词、媒体 URL、凭据或供应商原文直接展示给用户。无法识别原因时明确说明需要管理员核对，不臆测参数错误；分类不改变重试资格或资金处理。

Grok 同步 TTS 没有可查询的任务 ID。发送前持久化 `provider_inflight`；发送后连接异常、服务端异常或无法确认完整音频时不自动再次生成，并按[结果未知即释放](creative_studio.md#creative_unconfirmed_release)失败释放预扣。已确认输出先写临时存储，再持久化到画布私有素材；归档暂时失败只恢复存储，永久失败或副本过期按未交付释放，见[只为已交付的成品扣费](creative_studio.md#creative_delivery_billing)，不重发语音。音频仍遵循用户归属和七天有效期，获取播放地址不绕过私有素材鉴权。

音频请求地址复用正式 Voice 的版本路径规范化，裸主机 Base URL 自动补 `/v1`，显式代理前缀保持不变。确定的 404 按原失败释放流程处理，界面明确提示语音服务端点不存在；不通过换端点重发来猜测协议。地址约定见 [Grok 搜索与语音](../interfaces/grok_upstream.md#搜索与语音)。

图片和音频任务在建行前就与后台补偿共享任务锁，防止输入还在保存时被误判为准备失败；临时存储连接故障也不能被当作输入已丢失。完整的创建、租约丢失和恢复边界见[创作台生命周期](creative_studio.md#task_lifecycle)。已经失败且完成退款的任务保留原记录，不因服务升级自动重新生成。

文本执行在调用网关前持久化发送标记，真实推理传输限制同一执行只发送一次；认证刷新和计数查询不占生成次数。无响应、发送后中断或缺少可靠费用证据进入核对，只有本地准入失败或明确拒绝才安全结束。普通网关请求没有内部捕获标记，原异步用量记录与故障转移语义不变。文本正文随私人画布保存，媒体素材仍严格遵循七天有效期；执行 API 不返回内部账务证据、密钥或原始供应商响应。

<a id="grok_video_execution"></a>
## Grok 视频执行与恢复

Grok 视频以 `kind=video` 和 `endpoint=grok` 进入画布执行。提交前再次验证管理员白名单、用户分组权限、分组媒体开关、账号媒体资格和模型映射；只支持生成及最多一张图片参考，不开放视频编辑、扩展或视频/音频参考。参考图从已鉴权的私有素材读取并转换为 xAI JSON 的 `image.url`，浏览器不接触上游凭据。

`creative_grok_video_executions` 在调用正式网关前持久化发送栅栏，固定执行、用户、隐藏执行 Key 和分组。正式 Grok 路径保存 `legacy_video_tasks` 时，在同一数据库事务内绑定画布执行、原任务 ID 与原账号；同一个原 Key 与上游任务只能属于一个画布执行。关联表只保存恢复所需的阶段、归属和安全响应类别，费用、报价与扣款回执仍由原 Grok 任务账本负责。

恢复先读取已有栅栏和关联，不因进程重启、网络超时、目录变化或重复提交再次生成。尚未取得并持久化任务 ID 的未知受理保持 `running` 和 `CREATIVE_VIDEO_SUBMISSION_UNCONFIRMED`，需要核对原请求；上游不支持按客户端 ID 找回任务时，不能承诺自动恢复成品。明确的本地拒绝或上游拒绝才可结束为失败，已绑定任务始终按原任务状态恢复。

`LegacyVideoRuntime` 继续按原账号查询并执行完成后结算。画布只读任务状态和原资金回执：已完成但未 `settled` 时保留 `CREATIVE_VIDEO_SETTLEMENT_PENDING`；失败、取消或过期只有确认 `not_billable` 后才显示失败和未扣费，其他账务状态继续核对。这里没有可供画布释放的 Video 预扣，不能把未知受理或失败提示解释为退款。

只有原任务 `completed` 且账务 `settled`，才使用原用户、Key、分组、账号与任务关联读取 content，并归档为保留七天的画布私有素材。仅服务端可信画布上下文可让已绑定任务的读取不再经过当前余额消费准入，避免结算后余额不足阻止已付费成品归档；真实身份与归属校验继续执行，公网请求不能声明该上下文。缺少原身份、内容读取失败或归档失败时只恢复查询和存储，不换号取结果、不重新生成，也不重算或重复扣费。现有独立 Video 执行、预扣和归档链路保持原契约。迁移与回退要求见[Grok 画布视频增量升级](../operations/deployment_and_migrations.md#creative_grok_video_upgrade)。

<a id="frontend_delivery"></a>
## 前端构建交付

构建同时输出 `LICENSE.infinite-canvas` 与 `NOTICE.md`，与 React 静态资源一起嵌入二进制并随镜像交付，保留原项目的 MIT 许可与署名。

图片批次中任一子执行进入费用或受理核对时，整个结果节点显示核对状态，并保留已成功的图片；恢复正常进度或整批进入终态后清除该提示。折叠多图完全重合在节点边框内，只有主动展开才向外排列图片。

画布任务列表的只读查询采用 20 秒超时，包含响应头与正文读取，离开画布时取消。查询失败保留原任务和提交防重状态，只恢复状态查询，不重发生成；下一次查询成功后清除连接提示。节点错误条及核对状态可打开独立详情查看完整安全说明，查看不修改画布、任务或费用。

上传和拖放在发送前校验整批文件的类型、空内容和大小；非法文件不会导致同批部分素材先上传。进行中或响应未知的节点禁止通过替换素材清除原提交意图，上传回包也会复核任务与主图绑定，迟到响应不会覆盖新结果。连接了尚无可用素材的参考节点时阻止生成，不能静默退化成不带参考图的请求。视频节点可作为参考视频提交（`role=reference_video`），数量受目录 `max_reference_videos` 约束，为 0 或超出时在面板内说明原因且不提交；音频参考与图片生成中的视频参考继续拒绝。视频的参考图只有一张且无参考视频时作为首帧，多图或带参考视频时全部作为 `reference_image`，避免首帧与参考素材混用被协议拒绝。参考视频经[短期视频票据](../interfaces/cloud_canvas.md#video_reference_delivery)交付上游。

`frontend/canvas-app` 是独立 React 子包，避免与宿主 Vue/Tailwind 版本相互覆盖。宿主 `build` 先生成主站静态资源，再构建画布到 `backend/internal/web/dist/canvas-app`；子包不得清空上级目录。Docker 同时安装两份锁定依赖，最终仍由同一 Go 二进制提供页面和 API。

画布库、侧栏和节点编辑区沿用原项目的尺寸与布局；配色使用主站蓝白及中性深色主题。生成面板依附节点并抵消画布缩放，节点操作条使用屏幕坐标，参数和模型选择弹层通过同文档 Portal 脱离缩放容器。聚焦把节点、生成面板和底部工具栏一起计入可用空间，避免只居中节点而遮挡操作按钮。

生成配置节点沿用原版 340×240 结构，节点内包含生图/文本/视频/音频切换、连接输入计数、模型、参数和生成按钮；下方“组装提示词”单独展开。模型仍来自管理员目录，配置节点生成到新结果节点，图片批次继续在同一个结果节点叠卡。组装内容使用 `composerContent` 的纯文本 `@[node:<id>]` 标记，不保存 HTML 或脚本；留空时自动合并连接文本与素材，填写后仅使用显式引用，普通文字不会隐式带入未提及素材。发送时按当前连接顺序展开组、去重并重新编号；失效引用阻止新提交，不改写已经冻结的任务参数。

复制节点/组会重映射组装引用并清除执行关联；在途结果和来源配置保留唯一提交意图，撤销不能抹掉待确认请求或误触发新生成。终态节点仍可删除、复制和撤销。节点内部控件、引用菜单和组装输入与画布拖动手势隔离。

图片设置遵循目录的质量、尺寸、比例和 `output_counts` 总张数白名单；旧目录没有张数字段时维持固定单次输出数。独立 Video 清晰度使用三个预设和第四个自定义 p 输入，比例使用预设和自动选项，时长支持 1–60 秒；Grok 视频按自身目录限制为三个固定清晰度和 1–15 秒。界面、摘要与请求共用参数解析，尺寸宽高仍仅用于估算展示，不发送任意 W×H。自定义分辨率使用胶囊整体焦点样式，避免内部输入框出现重复边框。图片和视频生成状态在节点中央展示，重新生成保留旧媒体，加载层不阻挡拖动连线。连线预览在独立层按动画帧更新，支持从输入或输出端起拖并吸附节点主体，只有成功结束连线才更新云端文档。吸附时目标节点实线高亮，并在其上方标明“连接到”或“输入来自”哪个节点。拖出的线在画布空白处松手会弹出“新建并连接”菜单（文本、图片、视频、音频、生成配置），按拖出方向创建节点与连线；从输入端拖出时不提供没有输出端的生成配置。落点靠近任意节点、点击端点的待连接模式或菜单关闭都不新建，选择后只改画布文档，不触发生成或扣费。

图片、视频、文本节点的主提示词与展开提示词支持 `@` 引用已连接素材：菜单列出参考图缩略图与文本摘要，选择后插入“图片1”“文本1”等纯文本标签并在输入框内高亮，删除键整体删除标签。编号按提交时参考素材的连接顺序分类型计算，“图片1”即请求中的第一张参考图；标签只是提示词文字，不保存节点 ID，也不改变发送的素材集合。语音节点会逐字朗读输入，因此不提供 `@`。生成配置节点的显式引用仍由“组装提示词”的 `@[node:<id>]` 标记负责。

模型、参数、参考图等提交前校验失败时，原因显示在当前生成面板（或生成配置节点上方）且可关闭，不改动节点状态。已形成提交意图后被确定拒绝的请求在结果节点保留服务端原因；结果未知时节点同时显示服务端返回的原因与“待核对”说明，仍保留原键供核对，不改变重试、预扣或退款规则。

音频节点使用同一生成面板与弹层结构，提供 Eve、Ara、Rex、Sal、Leo，MP3/WAV，0.7–1.5 倍语速。输入是待朗读文本，可组合连接的文本节点；参考文本只拼接到当次请求，不写回节点提示词导致下一次重复朗读。不把图片、视频或音频引用送入 TTS。没有单独的声音指令字段，不展示 OpenAI 专用声音或未适配格式。生成状态在当前节点中央展示，完成后在当前节点播放与下载；播放控件与节点选择/拖动分离，播放不会触发生成和扣费。

画布平移、节点移动/缩放和框选共用捕获阶段的手势生命周期，弹层与表单输入不会启动画布拖动。失焦、丢失捕获、页面隐藏或漏收松手时结束手势并清除排队帧；正常松手提交最后一帧。预览、布局、主题、弹层和手势取消不会创建任务或触发结算。

已生成的视频通过捕获阶段独立选中节点，画面拖动区与底部原生播放控件分开；播放器保留播放、进度、音量、全屏和键盘操作。视频画面移动达到四个屏幕像素才记录拖动历史，普通点击不修改位置或保存画布；极小节点可通过标题拖动。选中和移动不重建视频元素或重置播放位置，也不触发生成或计费。

生成面板中的参考图缩略图可点击或用键盘打开独立预览弹层，不依赖是否已选模型或任务是否完成。每次打开都通过私有素材内容接口重新校验归属和七天有效期，不直接复用缩略图缓存；关闭、换图或退出会话后撤销预览专用对象 URL，迟到响应不得回填。预览不修改参考连线、画布文档或执行意图，也不会触发生成、预扣或退款。

首次开发需分别安装 `frontend` 和 `frontend/canvas-app` 依赖。`frontend` 的 `pnpm dev` 启动两套 Vite，宿主通过 `/canvas-app` 代理子服务，维持同源会话边界。生产不需要额外 Node 服务。
