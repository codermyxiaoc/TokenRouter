# 每日活动

本文描述每日充值礼包、累计充值奖励、累计消费奖励的资格、随机入账、幂等领取与数据保留边界。活动不包含邀请奖励，也不修改支付渠道的到账规则或模型计费价格。

<a id="daily_activity_configuration"></a>
## 配置与累计起点

系统设置中的“每日活动”通过独立管理员接口保存 `settings.daily_activity_config`，默认关闭。三类规则分别包含达标金额 `threshold` 与随机奖励上限 `reward_max`；金额最多两位小数，奖励范围为 0.10 至上限，包含端点。服务端使用密码学随机整数分抽取，每次直接增加个人余额。

`started_at` 在第一次开启活动时由数据库生成，客户端不能覆盖。首次开启前的充值、消费不补算；关闭再开启不会重置时间、累计进度或领取次数。关闭期间停止新领取，首次启用后的真实充值、消费仍持续累计。公开设置与 HTML 注入仅增加 `daily_activity_enabled`，不公开管理配置；保存后触发现有设置缓存刷新。

每日礼包以北京时间 00:00 换日，按当日到账本金达标，每天最多领取一次。充值和消费奖励使用累计金额，每达到一次门槛增加一次资格，未领取机会跨日保留。调整门槛后按新门槛重新计算累计资格，但已领取次数保留，不回滚已经发放的奖励。

<a id="daily_activity_eligibility"></a>
## 充值与消费口径

充值仅统计首次开启后已履约到账的在线余额充值订单，以 `completed_at` 为到账时间。金额使用站内 USD 本金 `amount - bonus_amount`，不使用可能为人民币等外币的 `pay_amount`，排除赠金、兑换码、后台调余额和钱包购买订阅。

已完成、部分退款和退款失败但仍有到账权益的订单可参与；已确认退款按权益退款比例扣减本金。退款处理中暂不增加资格，全额退款订单不计入。退款减少后续可领取次数，不自动追回已经领取的奖励。

消费来自最终资金结算事务中的 `SubscriptionAmountUSD + BalanceAmountUSD`，写入独立 `daily_activity_spending_events`。普通请求、单张异步图片、批量图片、创作台和 Video 捕获均覆盖；预占冻结、失败释放、零金额结算以及奖励入账不计消费。团队请求按实际付款 Owner 归属，行为成员不重复获得资格。

消费事件与扣款同事务提交，以 API Key 和结算请求 ID 唯一去重。仅新插入的事件同事务累加 `daily_activity_spending_totals`，活动进度直接读取用户累计值，避免每次扫描全部历史。未配置、未首次开启、无有效起点时跳过记录，不改变原扣款；启用后的数据库事件或累计值写入失败使资金事务一起回滚，避免余额和资格只有一边成功。消费金额保留 12 位小数，不能提前按奖励的两位精度截断。

<a id="daily_activity_claims"></a>
## 领取与并发边界

用户接口只从登录会话取得本人 ID，不接受客户端指定领取金额、资格金额或其他用户。服务端每次重新读取配置和资格，先对配置加共享锁，再对付款用户行加 `FOR NO KEY UPDATE` 锁，与既有资金锁兼容。同一事务保存每次奖励记录、批次结果和余额变动，不调用会增加累计充值额的后台余额调整方法。

领取请求必须携带 `idempotency_key`。同一用户相同键重放返回原随机结果；改变活动类型或单次/批量方式返回冲突。前端先将请求号存入当前用户的会话存储，存储不可用时不发送领取；任何非成功响应均保留原键，避免超时后再遇登录失效而丢失原请求号。每日礼包另有用户与日期唯一约束。全部领取单批最多 100 次，剩余次数返回页面继续领取，不清空未领取资格。

提交后同时失效鉴权与余额缓存；断连后重放也执行缓存补偿。关闭活动不影响读取本人分页历史，也不影响已完成请求的幂等重放。历史按每次奖励独立展示时间、活动类型和金额。

## 存储与接口

迁移 `300_daily_activities.sql` 新增活动配置、消费事件、用户消费累计表、领取批次和奖励明细。它们是持久资金与资格记录，不属于可清理的使用日志或运行时数据；备份恢复时应与用户余额一起保留。清理 `usage_logs` 不影响活动资格。不能独立清空领取记录，否则会恢复已消耗的机会。

| 接口 | 权限 | 用途 |
| --- | --- | --- |
| `GET /api/v1/daily-activities` | 用户 JWT | 三类活动的当前进度、已领与可领次数 |
| `POST /api/v1/daily-activities/claim` | 用户 JWT | `activity_type`、`all`、`idempotency_key` 领取 |
| `GET /api/v1/daily-activities/history` | 用户 JWT | 本人历史，`activity_type` 筛选与 `page/page_size` 分页 |
| `GET/PUT /api/v1/admin/settings/daily-activity` | 管理员 | 独立读取/保存活动开关与规则 |
