# 领域文档目录

> 上级目录：[工程文档](../index.md)

## 范围

本分类拥有跨多个模块维持的领域概念、业务规则、状态转换和不变量。HTTP 形状、配置键和第三方协议属于接口分类，运行流程属于运维分类。

## 文档

- [每日活动](daily_activities.md)：每日充值礼包、累计充值/消费奖励、随机余额入账和持久资格账本。读取时机：修改活动配置、领取资格、资金结算消费事件、幂等领取或活动历史时读取。

- [降智检测](intelligence_tests.md)：分组模型检测、Manxue 异步执行、结果留存、用户权限与画图隔离。读取时机：修改降智检测配置、检测开关、调度恢复、结果条或画图预览时读取。

- [工单](support_tickets.md)：个人工单、后台对话处理、订单归属、私有附件、功能开关、回复邮件与自动过期。读取时机：修改工单接口、状态、权限、附件或工单设置时读取。

- [身份与租户](identity_and_tenancy.md)：用户、七类认证身份、会话、绑定、自定义属性、角色、团队和权限边界。读取时机：修改登录、OAuth、身份绑定、TOTP/Passkey、用户属性、管理员权限、团队或用户归属时读取。
- [路由与结算](routing_and_billing.md)：API Key、分组、渠道、账号、调度、定价、媒体订阅倍率优先、配额和用量结算的关系。读取时机：修改模型路由、账号资格、渠道映射、限额、价格、媒体倍率或使用记录时读取。
- [网关策略控制](gateway_policy_controls.md)：Key、分组、渠道、账号和全局设置的协议准入、模型路由、fallback、隐私、推理、Header 与重试边界。读取时机：修改分组策略、渠道功能、账号限制或网关降级时读取。
- [用户平台额度](platform_quotas.md)：十五个平台的用户日/周/月 USD 限额、数据库准入、与资金同事务计数，以及默认值和管理重置。读取时机：修改平台额度默认值、窗口、缓存、结算或管理重置时读取。
- [支付与权益](payments_and_entitlements.md)：余额、兑换、订阅计划、支付订单、回调与权益发放不变量。读取时机：修改支付、充值、订阅、兑换码、额度包或订单状态时读取。
- [推广与返利](promotions_and_affiliates.md)：邀请码、订单返利、冻结解冻、余额转入、注册优惠码和幂等约束。读取时机：修改推广关系、返利比例/上限、支付履约赠送或 Promo Code 时读取。
- [内容审核与风险处置](content_moderation.md)：审核模式、规则/API Key 池、同步阻断、异步观测、自动封禁和安全消息边界。读取时机：修改网关内容审核、关键词/hash、风险日志或处置策略时读取。
- [API Key 模型重定向](api_key_model_redirects.md)：单 Key 模型重定向规则及其在路由和响应中的位置。读取时机：修改 API Key 模型映射、模型列表或请求/响应模型元数据时读取。
- [复合 API Key](composite_api_keys.md)：一个 Key 绑定多个分组时的前缀选组和入口限制。读取时机：修改复合 Key、前缀解析、跨分组模型或聚合模型列表时读取。
- [智能路由 API Key](smart_routing_api_keys.md)：最多二十个有序跨平台候选分组的目录匹配、可调度检查、上游失败换组和冷却边界。读取时机：修改智能路由配置、无前缀跨组选组、故障冷却、模型聚合或探针防错组时读取。
- [批量图片作业](batch_image_jobs.md)：批量图片作业的持久状态、队列、供应商执行和结算生命周期。读取时机：修改批量图片 API、worker、对象存储、状态恢复或计费时读取。
- [异步图片与任务记录](media_tasks.md)：第三方 API Key 异步图片、S3 保存清理、图片/视频状态观测、管理员账务核定与失败超时释放。读取时机：修改异步图片、任务记录、存储保存期、资金核对或自动过期时读取。
- [独立视频平台任务](video_tasks.md)：Video 持久异步归属、幂等提交、预留、捕获/释放及恢复边界。读取时机：修改 Video 生成、轮询、取消、额度事务或后台恢复时读取。
- [云端无限画布](cloud_canvas.md)：私人画布、生成配置与图片/文本/视频/Grok TTS 节点、云端素材七天留存、后台归档和 React 子应用会话隔离。读取时机：修改新创作台、画布 API、素材保存清理或生成关联时读取。
- [创作台任务](creative_studio.md)：图片生成/编辑/局部重绘任务、隐藏执行 Key、Redis 临时数据与计费恢复。读取时机：修改创作台图片 API、worker、计费或审核时读取；旧本地前端说明仅作旧任务兼容边界。
